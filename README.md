# 동네26
서울시(구)민들을 위한 정보 공유 플랫폼

## 프로젝트 목적
서울시 행사, 일자리, 정책 정보들을 한 곳에서 편리하게 확인할 수 있으며, 구민들끼리 커뮤니케이션을 도모하여 빠르게 정보를 얻을 수 있는 환경 조성

## 주요 기능 & 기술
[정보 전달 기능] <br>
  - **공공데이터 API**를 이용한 각종 게시판 및 커뮤니티 CRUD
  - 행사가 열리는 장소 지도(**KakaoMap API**) 통해 시각화된 정보 제공 <br>
[사용자 편의성] <br>
  - 게시판 페이징 및 카테고리를 이용한 검색 기능 구현
  - 저장하고 싶은 게시글 북마크 <br>
[사용자 최적화] <br>
  - REST API를 통한 카카오, 구글, 네이버 **소셜 로그인**
  - HTML, CSS, JavaScript 및 Bootstrap을 사용한 **반응형 웹 디자인**
  - 폼 형식으로 관리자에게 이메일을 전송하여 건의 사항을 접수

## 역할과 기여
  - 데이터베이스 설계 및 UI 구상
  - 클래스 다이어그램, UI 계획서, ER 다이어그램 제작
  - 검색, 필터링, 페이징 기능을 포함한 공공데이터 기반 서울시 정책 게시판 제작
  - 문화행사 게시글별 지도 정보 제공
  - 데이터베이스 연동 게시글 북마크 기능 구현
  - STMP기반 관리자 문의 폼 전송 기능 구현
